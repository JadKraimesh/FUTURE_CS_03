# FUTURE_CS_03 - API Security Risk Analysis

## Task
Cyber Security Internship Task 3 by Future Interns

## Objective
Perform a read-only API security risk analysis on public/demo APIs and identify common API security risks, authentication weaknesses, and excessive data exposure issues.

## Scope
This project focused only on ethical, read-only API analysis using public demo APIs.

No exploitation, bypass attempts, flooding, or harmful activity was performed.

## Tools Used
- Postman
- Browser DevTools
- ReqRes API
- JSONPlaceholder API
- GitHub
- Canva

## Assessment Areas
- Authentication requirements
- API headers and responses
- Excessive data exposure
- Open endpoints
- Rate limiting observations
- Input validation observations
